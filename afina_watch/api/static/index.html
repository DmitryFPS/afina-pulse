Подключение источников

Сначала выбирается способ входа. Для закрытых чатов Telegram нужна пользовательская сессия. Для Facebook Graph отдаёт только страницы и группы, которыми вы управляете. Подключите хотя бы одну платформу.

Telegram
не подключено

Рекомендуемый путь. afina-tdl уже держит MTProto-сессию ваших подписок. Watch только читает поток.

Официальный вход MTProto: номер → код из приложения или SMS → облачный пароль 2FA. api_id и api_hash — с my.telegram.org.

Готовый файл Telethon/Pyrogram (.session) или каталог tdata / tdl.

Bot API не видит личные чаты и закрытые группы, куда бот не добавлен.

Facebook
не подключено

User или Page token. Watch проверит Graph /me и список страниц. App ID + Secret нужны, чтобы обменять токен на long-lived.

Официальный Facebook Login. Код вернётся на callback, Watch сам обменяет его. Личная лента через Graph недоступна.

Для ленты и чужих групп: JSON из Forage / fbn / расширения в каталог inbox.

QR Telegram: Settings → Devices → Link Desktop Device. Cookie-скрейп Facebook в продукт не встроен.
